# pin-pok — Poker Assistant для Pinco

Chrome-расширение читает стол Lucky Chip Hold'em (Pinco и зеркала) и подсказывает действие. Карты берёт локальный Python-сервер (OpenCV), банк и стеки — из HTML.

Подсказки показываются в **отдельном окне**, не поверх стола. Его можно поставить рядом с браузером или на второй монитор.

Репозиторий: https://github.com/ZigelmanMi/pin-pok

## Как это работает

Игра рисует карты на WebGL-холсте (PixiJS), из HTML их не прочитать. Расширение раз в ~2 секунды снимает вкладку и шлёт PNG на `http://127.0.0.1:8765/read`.

```
браузер (Pinco)                    отдельное окно виджета
   │                                      ↑
   ├─ HTML → банк, стек, ники, игроки     │
   │                                      │
   └─ скриншот вкладки                    │
         ↓                                │
   python3 vision_server.py               │
         ↓  белые карты → ранг + масть    │
   мои карты / доска  ────────────────────┘
         ↓
   эквити: префлоп GTO, постфлоп Монте-Карло
         ↓
   FOLD / CHECK / CALL / RAISE
```

| Что видно в виджете | Откуда |
|---|---|
| Мои карты, доска | Python-зрение (`src: py`) |
| Банк, ставка, стек, игроки | HTML стола |
| Рекомендация | GTO / Монте-Карло (GigaChat по желанию) |

Если Python-сервер выключен, карты часто пустые.

## Как запускать (каждый раз, когда играете)

Нужны **два** шага. Порядок такой.

### 1. Сервер зрения — не закрывать терминал

Один раз на машине:

```bash
cd /home/z/pok2
python3 -m pip install -r requirements.txt --break-system-packages
```

Потом перед игрой:

```bash
cd /home/z/pok2
python3 vision_server.py
```

Должно напечатать: `Poker card vision: http://127.0.0.1:8765/read`.

Проверка: `curl http://127.0.0.1:8765/health` → `{"ok":true,...}`.

### 2. Расширение в Chrome

Первый раз:

1. `chrome://extensions`
2. Включите **Режим разработчика**
3. **Загрузить распакованное** → папка `/home/z/pok2` (там `manifest.json`)

Каждый раз / после обновления файлов:

1. На карточке расширения нажмите **Обновить**
2. Откройте Pinco, **F5**
3. Кликните **иконку** расширения на панели Chrome — откроется виджет

Виджет — отдельное окошко. Перетащите его **в сторону от стола**. Если закрыли — снова кликните иконку или Tab на столе.

В виджете: версия **v3.3.15**, `src: py`, карты и рекомендация.

### 3. За столом

- Стол полностью виден (не перекрыт DevTools).
- Чем больше окно Pinco, тем точнее карты.
- Если зрение ошиблось — внизу виджета поля «Мои карты» / «Доска», кнопка **Посчитать**.

## Опционально: GigaChat

Без ключа рекомендация идёт по GTO / Монте-Карло.

```bash
cp secrets.example.js secrets.js
# впишите ключ в secrets.js, затем Обновить расширение
```

`secrets.js` в git не попадает.

## Если карты пустые

1. Жив ли сервер: `curl http://127.0.0.1:8765/health`
2. В виджете `src: py`? Если нет — Python не ответил.
3. Обновить расширение + F5.
4. Убрать DevTools с области стола.
