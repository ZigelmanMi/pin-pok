# pin-pok — Poker Assistant для Pinco

Chrome-расширение читает стол Lucky Chip Hold'em (Pinco и зеркала) и подсказывает действие. Карты берёт локальный Python-сервер (OpenCV), банк и стеки — из HTML.

Репозиторий: https://github.com/ZigelmanMi/pin-pok

## Как это устроено

Игра рисует карты на WebGL-холсте (PixiJS), поэтому из DOM их не достать. Расширение раз в ~2 секунды снимает видимую вкладку и отправляет PNG на `http://127.0.0.1:8765/read`.

```
браузер (Pinco)
   │
   ├─ HTML → банк, стек, ники, число игроков
   │
   └─ скриншот вкладки
         ↓
   vision_server.py  (должен быть запущен)
         ↓  card_vision.py: белые карты → ранг + масть
   мои карты / доска
         ↓
   эквити: префлоп GTO-таблица, постфлоп Монте-Карло
         ↓
   рекомендация: FOLD / CHECK / CALL / RAISE
```

Виджет в правом верхнем углу стола (его можно перетащить):

| Поле | Откуда |
|---|---|
| Мои карты, доска | Python-зрение (`src: py`) |
| Банк, ставка, стек, игроки | HTML стола |
| Рекомендация | GTO / Монте-Карло (GigaChat — по желанию) |

Если Python-сервер выключен, расширение откатывается на слабое JS-чтение (карты часто пустые).

## Запуск

Нужны **оба** процесса: сервер зрения и расширение.

### 1. Сервер зрения

Один раз:

```bash
cd pin-pok
python3 -m pip install -r requirements.txt --break-system-packages
```

Каждый раз, когда садитесь играть (окно не закрывать):

```bash
python3 vision_server.py
```

Должно появиться: `Poker card vision: http://127.0.0.1:8765/read`.

Проверка: в другом терминале `curl http://127.0.0.1:8765/health` → `{"ok":true,...}`.

### 2. Расширение Chrome

1. Откройте `chrome://extensions`
2. Включите **Режим разработчика**
3. **Загрузить распакованное** → укажите папку этого репозитория (там `manifest.json`)
4. Нажмите иконку расширения один раз на вкладке Pinco (выдаёт доступ к вкладке)

После обновления файлов снова нажмите **Обновить** на карточке расширения, затем **F5** на Pinco.

### 3. Игра

- Стол должен быть **полностью виден** (не перекрыт DevTools, не свёрнут).
- Чем больше окно стола, тем точнее карты.
- В виджете: версия **v3.3.13**, `src: py`, карты и рекомендация.
- Нет карт — **Tab**, ручной ввод (например `Ah Kd` и флоп `5s Td Jd`).

## Опционально: GigaChat

Без ключа рекомендация считается по GTO / Монте-Карло — этого достаточно.

Чтобы подключить LLM:

```bash
cp secrets.example.js secrets.js
# впишите ключ в secrets.js
```

`secrets.js` в git не попадает.

## Файлы

| Путь | Роль |
|---|---|
| `manifest.json` | Chrome MV3 |
| `background.js` | скриншот, запрос к Python, эквити, рекомендация |
| `content.js` / `content_iframe.js` | хук на зеркала Pinco и игровой iframe |
| `card_parser.js` | банк/стеки из HTML + HUD |
| `vision_server.py` | HTTP `127.0.0.1:8765` |
| `card_vision.py` | поиск карт и чтение ранга/масти |
| `card_templates/` | шаблоны рангов (в т.ч. десятка `T`) |

Проверка зрения на известных снимках:

```bash
python3 card_vision.py --selftest
```

## Если карты пустые

1. Жив ли сервер: `curl http://127.0.0.1:8765/health`
2. В виджете `src: py`? Если `none` / `shot` — Python не ответил, смотрите терминал сервера.
3. Обновите расширение и нажмите F5.
4. Уберите DevTools с области стола, разверните окно.
5. Tab — ручной ввод карт.
